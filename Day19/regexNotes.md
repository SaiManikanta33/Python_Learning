    Common Regex Patterns

Pattern             Meaning
  \d                Digit
  \D              Not A digit
  \w(small)     Letter,digit,or underscore
  \W(capital)   Not a word character
  \s            Whitespace
  .             Any character
  +             One or More
  *             Zero or more
  ?             Optional
  ^             Start of string
  $             End of string
